Guia de Actualizacion del Sistema
Dos metodos simples para mantener tu sistema siempre actualizado: desde la app o con un pendrive.
v2.9.63+ | Agosto 2026
Opcion 1
Actualizacion en Linea (desde la App)
Todo automatico: descarga, instala y migra sin tocar nada. Solo necesitas conexion a internet.
1
Abrir Configuracion
En el sistema, ve al menu lateral y haz clic en Sistema, luego en la pestana Configuracion. Desplaza hacia abajo hasta encontrar la seccion de Actualizaciones.
2
Buscar Actualizaciones
Haz clic en el boton "Buscar Actualizaciones". El sistema consulta GitHub Releases (o el archivo local versions.json si no hay internet) y muestra todas las versiones disponibles con sus changelogs.
3
Revisar la lista de versiones
Cada version muestra un resumen de cambios. Las versiones nuevas aparecen con borde verde. Haz clic en una version para expandirla y ver el changelog completo, notas y fecha.
4
Confirmar y Actualizar
Haz clic en el boton verde "Actualizar a vX.X.XX". El sistema pedira confirmacion. Acepta y veras la barra de progreso con cada paso: respaldo, descarga, extraccion, copia de archivos y migracion de base de datos.
5
Reiniciar el sistema
Cuando termine, ejecuta INICIAR-TODO-OCULTO.vbs (doble clic), espera 10-15 segundos y abre el navegador. La nueva version estara activa.

Ventaja de este metodo
El sistema crea un respaldo automatico antes de actualizar. Si algo sale mal, puedes restaurar desde la carpeta BACKUP_AUTO_*/. Tambien puedes descargar el ZIP de cada version para tenerlo de respaldo.
Opcion 2
Actualizacion Local (con Pendrive)
Para cuando no hay internet en la tienda. Descargas el ZIP en otra computadora, lo pasas al pendrive y ejecutas el instalador.
1
Descargar el ZIP (con internet)
Desde cualquier computadora con internet, descarga el ZIP de la version desde github.com/csglider/MyeCommerce-v2.9.20/releases. Descarga el archivo MyeCommerce-vX.X.XX-INSTALACION-LIMPIA.zip. O usa el boton "Descargar ZIP" dentro del sistema.
2
Copiar al pendrive
Conecta tu pendrive (USB) y copia el archivo .zip descargado. El archivo pesa menos de 2MB, asi que cualquier pendrive funciona.
3
Copiar a la carpeta del sistema
En la computadora de la tienda, conecta el pendrive y copia el ZIP a la carpeta donde esta instalado MyeCommerce (donde esta package.json). Renombra el archivo a: temp_update.zip
4
Ejecutar la actualizacion
Haz doble clic en ACTUALIZAR.vbs. Este script hara todo automaticamente: cerrara los servicios, creara un respaldo completo comprimido en .zip, extraera la nueva version, reemplazara archivos (sin tocar la base de datos ni las imagenes), instalara dependencias y migrara la base de datos.
5
Reiniciar el sistema
Cuando el script termine, ejecuta INICIAR-TODO-OCULTO.vbs (doble clic), espera 10-15 segundos y abre el navegador. Verifica la nueva version en la esquina superior derecha.

Que se preserva al actualizar
La base de datos (prisma/dev.db), las imagenes de productos (data/uploads/), los respaldos (BACKUPS/), el logo de la tienda, los certificados de Caddy y la configuracion del agente de impresion. Nada se pierde.
Si algo sale mal - Restaurar
El respaldo se guarda como BACKUP_PRE-ACTUALIZACION_vX.X.XX_YYYY-MM-DD.zip. Para restaurar: descomprime ese archivo, copia dev.db a la carpeta prisma/, copia uploads/ a data/ y reinicia. Tambien puedes restaurar cualquier version anterior directamente desde la app (boton naranja "Restaurar vX.X.XX").
Versiones futuras
Cada nueva version de MyeCommerce incluye esta guia actualizada dentro de public/GUIA-ACTUALIZACION.pdf. Consultala en cualquier momento directamente desde el sistema.
